# Internal staging

Internal Next.js staging environment. Not for public listing.

## Stack

- Next.js 16 (App Router) · React 19
- Tailwind CSS v4 · TypeScript
- Turbopack

## Local

```bash
npm install
npm run dev   # http://localhost:3000
npm run build
```

> Diese Bereitstellung ist als `noindex` / `Disallow: /` markiert.
> URL bitte nicht öffentlich teilen.
